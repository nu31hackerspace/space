# Сайт NU31 Hacker Space

Це ось цей [сайт](https://nu31.space/)

### Технології

Основна філософія проекту — це зробити роботу з кодом максимально простою, для того, щоб більше людей могли доєднатися до його розробки.

Проект — це monorepo, в якому і сайт, і backend до нього. Cайт статичний, і може працювати без backeтnd

Для роботи з CSS використовуємо [tailwind 4](https://tailwindcss.com/)

### Як запустити

```bash
npm install
```

```bash
npm run dev
```

Якщо на вашому комп'ютері 3000 зайнятий, буде спроба запуститися на 3001, 3002, ...

## Проект відкритий до будь-якої допомоги

### Блог і RSS

Публікації зберігаються у `content/blog/*.md`. Щоб додати допис, створіть Markdown-файл із назвою латиницею через дефіси та відкрийте pull request. Назва файлу стає постійною адресою `/blog/<назва-файлу>/`; після публікації не перейменовуйте його без редиректу.

На початку файлу вкажіть `title`, `description`, `author` і `tags` (список рядків). За замовчуванням дата публікації — дата першого комміту файла. Поле `date` задає її вручну у форматі `РРРР-ММ-ДД`. Наприклад:

```md
---
title: 'Новини майстерні'
description: 'Короткий опис допису.'
date: '2026-10-31'
author: 'Команда NU31'
tags: ['новини']
---

Текст допису.
```

Кожен Markdown-файл у `content/blog/` з'являється у блозі та RSS після збірки. Для локальної перевірки виконайте `npm run generate`: сторінки з'являться в `.output/public/blog/`, стрічка — у `.output/public/rss.xml`.
